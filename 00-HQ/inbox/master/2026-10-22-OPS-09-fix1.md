## Known limits (left on purpose)
- **P3-8, runtime id:** still `executable|version|-s`. An in-place package reinstall in the same `runtimes/<id>` does not
  change the key. Not trivial to do well (dist-info names miss editable and same-version reinstalls), so it stays a
  limit. Use `--fresh` after reinstalling packages in place.
- **Ignored files** (local configs, downloaded fixtures) are still not in the key. Untracked non-ignored files from the
  whole repo now are.
- **A tree that a real test edits** during the run (any test writing inside the repo) makes every run "not cached".
  This fails safe (it re-runs). If it shows up in the equivalence run, it is a finding about that test.
- **Tool crash mid-run:** the parent exits 2. Workers already started are not killed; they finish by themselves and their
  `wnc-par-<pid>` folder stays in TEMP.
- **sys.path match** is checked against `python -m unittest discover` with the same interpreter (3.12.15 runtime here).
  With `-P`/`PYTHONSAFEPATH`, the tool leaves the path alone, as serial does.
- Unchanged from the build report: the equivalence run on the real repo, the ≤ 30 min wall time, heavy.sh `psuite`, and
  Mac (not run; only stdlib and `git` were added).
