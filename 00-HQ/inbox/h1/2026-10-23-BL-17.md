## What changed (the editor's view first)
- A second WhyNot Cut install on the same account (a try or dev marketplace, or a `--plugin-dir` checkout) no
  longer takes over the first one's options. Each install reads its own `~/.whynot-cut/plugin-options.<marketplace>.json`
  first (`inline` for a checkout), then the shared `plugin-options.json`. Earlier releases and the installer write
  the shared file, so it is still read for one release.
- `WHYNOT_OPTIONS_FILE` still names the one file read and written (never keyed).
- REL-PREVIEW (1): `reel doctor` from a second engine home never offers, and never runs, `--fix --all-clients`
  against a clients root it did not set. The hint names the cause and the fix (set this install's `clients_root`),
  and `who` is `editor`. `--fix --root` still marks the editor's own client. A clients root from the environment
  counts as this home's.
