### P2-1 — three real "not yet" skips added since p3.1 are classed `platform/tool`, so the gate run passes them
`tools/skip_audit.py:194` (`PLATFORM_RE` matched on the enclosing `if` test) + `:57-60` (`.is_file()` / `.exists()`).
On the tip, with `--since v3.0.0-p3.1 --all`, these sites are on lines added since the tag (checked with

These are exactly the "green only because skipped for now" tests the card's Goal is about. The spec's
`platform/tool` list does name `.is_file()/.exists()` ("a file that exists only in a repo checkout"), but the spec
also says the classes are a helper and that a temporary marker wins over a platform look; here the reason text
says plainly that the work is unfinished. The report's "needs the executor's attention" list does not name them,
so nothing surfaces them to the executor. Same root cause, wider: `PLATFORM_RE` (re.I) is also run over the
reason prose (`:194`), so `\w*AVAILABLE\b` matches "available"/"unavailable", `\bNODE\b` matches "node",
`\bwindows\b`, `\bram\b` match prose: `self.skipTest("token support not available yet")` under any condition is
`platform/tool` (no instance on the tip today besides the three above, but the gate exists for the next one).
**Fix:** a temporary-wording check before the platform branch: if the reason or the skip's comment matches
e.g. `\byet\b|not (?:built|applied|ported|generated|committed)|\bexecutor\b|\bpatch\b`, the site cannot be
`platform/tool` (class it `unknown`, so `--since` fails it; or `dated` if the master prefers). Add the three shapes
above as fixtures in a `case_*.py` and a test that they are not `platform/tool`. If the master rules the spec
literal wins, at least list these three in the report for the executor and write the limit in the docstring.
