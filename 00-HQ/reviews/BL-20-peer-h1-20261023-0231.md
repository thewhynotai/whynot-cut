## Findings (new this round; no P1, no P2)

### P3-1: reason prose from a *named* reason still goes through the full `PLATFORM_RE`
`tools/skip_audit.py:203`: `ast.unparse(r) for r in resolved` includes the string Constants that a reason name resolves
to. So the narrowing asked for in FIX item 1 ("stop matching PLATFORM_RE against free reason prose") applies only to literal
reasons. I probed this through the queue:
`MSG = "the feature is not available"` + `@unittest.skipIf(FLAG, MSG)` → **platform/tool**. The literal form gives unknown.
`MSG = "waits for the windows team"` also gives platform/tool. The named-reason shape is real in the tree
(`requires_hypothesis = unittest.skipUnless(AVAILABLE, INSTALL_HINT)`, `NEEDS_TOOLS = …skipUnless(TOOLS_OK, "…")`). The
temporary check still catches "yet/executor/patch" wording first, so only prose without those words slips through.
**Fix:** at `:203` use `ast.unparse(r) for r in resolved if not isinstance(r, ast.Constant)` (their strings are already in
`reason`, which `REASON_PLATFORM_RE` checks), and add one subTest with a named reason to
`test_ordinary_words_in_a_reason_are_not_a_platform_look`.

### P3-2: temporary wording at the condition's assignment is not read (dated markers there are)
`tools/skip_audit.py:201` runs `TEMPORARY_RE` only on the reason and the comments in the skip's own window (3 lines above). The
`raw` text that `resolve()` gathers (comments above the assignment, the `except` block) feeds `DATED_RE` but not
`TEMPORARY_RE`. Probe: `# the lib is not ported yet` / `HAVE_LIB = (P / "lib.py").is_file()` with the skip 4+ lines below →
**platform/tool**. The same comment on an `except ImportError:` line gives unknown only when it happens to fall within 3 lines of the
decorator. There is no instance on the tip (I grepped the module-level `HAVE_*/NODE/*_PRESENT/…is_file()` assignments and the
`except` lines with temporary words; none). It is the same 61feeb2 hiding shape as before, with "not yet" words instead of a dated marker.
**Fix:** search `TEMPORARY_RE` over the comment part of `raw` too (or over `raw` in full), and add a test with a comment on the
assignment 5 lines above the skip.
