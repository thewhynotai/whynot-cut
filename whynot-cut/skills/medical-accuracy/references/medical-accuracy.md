# Medical Content Accuracy

Write `01_analysis/medical-content-review.md` for every video:

1. **Claims inventory** — every medical statement the speaker makes: quote, timestamp, type (fact / recommendation /
   warning / qualifier / opinion), whether it appears on screen.
2. **On-screen wording audit** — each graphic's text vs. the speaker's exact words; note any shortening and confirm meaning is unchanged.
3. **Qualifiers preserved** — list warnings/conditions and the graphics that carry them.
4. **Terminology** — Latin/Arabic terms, spelling to verify (drug names, lab tests, procedures).
5. **Uncertain transcription** affecting medical meaning — must be verified before captions are final.
6. **Visuals needing approval** — every diagram, claim card, lab/dose values, any image implying a result.
7. **Not done on purpose** — e.g. "no anatomy illustration: no accurate approved asset available".

Rules: no invented claims/evidence/statistics; no fabricated patient or before/after images; never alter
warnings; uncertain facts are flagged, not "fixed".
