# WhyNot Cut 3.0 Arabic guide — round 3 (Addendum G premium bar) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring the Arabic PDF guide up to the Addendum G bar: zero «مش فاهم» moments for both personas, a troubleshooting chapter where every entry has a fix, macOS first, a tester welcome page, documentation that looks like a $1,000/month product, then (P1) docs-site content and the release-notes/What's-new texts.

**Architecture:** This round keeps the round-1/2 pipeline (HTML chapters → headless Edge → PDF, `build.py` lint + `guide-ar/tests`). It adds:
- two lints: a developer-word lint and a troubleshooting-shape lint;
- one new chapter section, the tester welcome page;
- a CSS design pass;
- a P1 export (`site.py`) that turns the same chapter sources into docs-site content, so there is a single source for both.

**Tech Stack:** HTML/CSS, Python 3 (`build.py`, `unittest`), Edge headless, pypdfium2 for QC renders.

**Spec:** `docs/superpowers/specs/addendum-g/ADDENDUM-G-premium-1000-bar.md` (G2 Clarity, G5, G9 G-T10, G10, G11), together with the round-2 plan `docs/superpowers/plans/2026-10-13-3.0-phase-10-guide-round-2.md` and its rulings in `.superpowers/sdd/2026-10-13-3.0-phase-10-guide-round-2/progress.md`.

## Review Focus
- **A dev word inside a command box or code token.** The developer-word lint must ignore `<code>`/`.cmd` content and `<!-- -->` comments, and flag only visible prose. Owner: Task 2 test `test_no_dev_words_in_prose`. One case it must catch: «JSON» in a `<p>`. One case it must pass: a `<code>` holding `.json`.
- **A troubleshooting entry with a cause but no action.** It must fail the shape lint. Owner: Task 3 test `test_troubleshooting_entries_have_three_parts`.
- **A two-platform step written Windows first.** The order lint must flag it. Owner: Task 4 test `test_macos_listed_first`. It applies to every `.platforms` block and to every pair of `<h3>` headings named Windows/macOS.
- **The agency-owner persona meets a price or licence claim the guide cannot back.** The guide states no price and no licence terms. Owner: Task 5 reader pass. Check: grep visible text for «$», «دولار», «اشتراك», «ترخيص», which must appear 0 times outside team comments.
- **A long Arabic heading or a new `.platforms` block that breaks the page layout.** Owner: Task 7. Every page is viewed, and each page has a row in the per-page checklist.
