# WhyNot Cut 3.0 — Phase 10 Arabic guide track Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A reproducible, branded, RTL-correct Arabic PDF guide (`whynot-cut/docs/WhyNot-Cut-Guide-AR.pdf`) with the
chapters that are stable now written and the rest as marked skeletons, every page viewed.

**Architecture:** HTML/CSS sources in `guide-ar/` (a shell `index.html` + one file per chapter in `guide-ar/chapters/`),
assembled by `guide-ar/build.py` into one HTML file, printed by headless Edge/Chrome. Running header/footer and page
numbers come from CSS `@page` margin boxes (Chromium 131+; Edge 155 here); PDF bookmarks from Chromium's
`--generate-pdf-document-outline`; TOC page numbers from a second pass that reads the first PDF's outline with pypdf.
QC renders every page to PNG (`guide-ar/render_pages.py`, pypdfium2) and a human/agent views each one.

**Tech Stack:** HTML5/CSS (print), Python 3.12 stdlib + pypdf (engine venv) for build; pypdfium2 + Pillow for QC
renders (a scratch venv, not shipped); fonts are the upstream STATIC TTFs (OFL, unmodified; Chrome would embed
variable fonts as Type3): Alexandria 5.013 statics (github.com/Gue3bara/Alexandria), Inter 4.001 (rsms/inter release
4.1), Syne 2.200 Bold (gitlab.com/bonjour-monde/fonderie/syne-typeface), IBM Plex Sans Arabic Light/Regular/SemiBold and
IBM Plex Mono Regular (github.com/google/fonts).

**Spec:** `docs/superpowers/specs/2026-10-11-whynot-cut-3.0-master-plan.md` — D13, D16, §5.4, §7 Phase 10
(T10.1–T10.3), Appendix D, Appendix E; brand kit `docs/review/2026-10-11/magnific-brand.md` Part 2 §2.6b.

## File structure

```
guide-ar/
  index.html            shell: <head>, cover, TOC container (<nav id="toc">), <!--@chapters-->, back cover
  styles.css            tokens, @font-face, @page rules, components (.tip .warn .todo .shot .steps .cmd table)
  chapters/NN-slug.html one <section class="chapter" id="chNN"> per Appendix E chapter, 01…16
  fonts/<family>/       font files + OFL.txt
  img/                  logo-white.svg (copy of brand/logo.svg), cover art if any
  build.py              assemble → lint → print → read outline → fill TOC → print → copy
  render_pages.py       PDF → PNG per page (QC only; needs pypdfium2)
  tests/test_build.py   unittest for build.py helpers + PDF checks
  tests/reel-commands.txt  snapshot of `reel --help` command names
  .gitignore            .build/
```

## Interfaces (build.py)

- `assemble(root: Path) -> str` — shell with chapters (sorted by file name) spliced at `<!--@chapters-->`, TOC built
  from every `h1.ch-title` and `h2` with an `id` (entries `<a href="#id"><span>title</span><span class="pg"
  data-for="id"></span></a>`).
- `lint(html: str) -> list[str]` — problems: Latin/digit run of ≥2 chars matching a command/path/time/URL pattern
  (`/whynot-cut:`, `reel `, `\`, `/`, `\d\d:\d\d`, `@`, `.md`, `.mp4`, `http`) outside `<bdi dir="ltr">`; any
  Arabic-Indic digit `[٠-٩]` inside a `<bdi>`; any `id` duplicated; any `href="#x"` with no `id="x"`; the strings
  `Gate 0`, `Gate 1`, `Gate 2` outside `#ch16`; `logo-dark`.
- `find_browser() -> Path` — Edge then Chrome (Windows paths, macOS `/Applications/...`, `PATH`), env `WNC_BROWSER` wins.
- `print_pdf(html_path: Path, pdf_path: Path, browser: Path) -> None` — `--headless --disable-gpu
  --no-pdf-header-footer --generate-pdf-document-outline --print-to-pdf=<pdf>`; backgrounds via CSS
  `print-color-adjust: exact`.
- `outline_pages(pdf_path: Path) -> dict[str, int]` — heading text → 1-based page (pypdf outline).
- `fill_toc(html: str, pages: dict[str,int]) -> str` — writes the numbers into `.pg[data-for]`.
- `main()` — `python guide-ar/build.py [--out PATH]`; default outputs `whynot-cut/docs/WhyNot-Cut-Guide-AR.pdf` and
  `dist/WhyNot-Cut-Guide-AR.pdf`; exits 1 on lint problems or TOC/outline mismatch; prints page count.
- `render_pages.py <pdf> <out_dir> [--scale 1.5]` → `page-001.png` … and prints the count.

Run with the engine venv python (has pypdf): `~/.whynot-cut/venv/Scripts/python.exe guide-ar/build.py`.
