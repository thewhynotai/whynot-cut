## Global Constraints (bind every task)

- Repo root `WhyNotCut/`; branch `release/3.0`; one commit per task (conventional message ending with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`). Tests `bash tools/test.sh`; TDD; count never drops.
- Host-plugin **sources** live in `WhyNotCut/adobe/` (`premiere-uxp/`, `cep-bridge/`, `panel-ui/`); **built artefacts**
  go to `whynot-cut/adobe/` (`WhyNotCut-Premiere-<v>.ccx`, `WhyNotCut-Bridge-<v>.zxp`). The engine still works from
  `whynot-cut/templates/premiere/cep_bridge` until T6.3 moves the CEP sources; keep one source of truth (move, don't
  copy) and update `ppro_bridge.install()` and the tests accordingly.
- Protocol number **4** in the heartbeat, the daemon, the panels and the contract. Requests
  `{protocol, id, action, data, expires_at}`; results `{ok, action, readback{…}, error?, how?}`.
- Daemon security: bind `127.0.0.1` only; random free port; 256-bit token in `~/.whynot-cut/bridge/engine.json`
  (user-only permissions); reject Host ≠ `127.0.0.1:<port>`/`localhost:<port>`; reject browser Origins (allowlist the
  exact Origin UXP sends, recorded in the spike); message size caps; rate limits; **no run-arbitrary-script endpoint**;
  schema-validated commands; audit log. Token never in a URL, never logged.
- Branding (D13 / Appendix D): tokens `--twn-*` (`#5400FB` fill only, `#9D6BFF` for violet text on dark, `#D95C9B`
  accent, `#390796`, gradient `#D95C9B→#5400FB`), Syne (display), Inter (UI), IBM Plex Sans Arabic (Arabic); header
  "WhyNot Cut" + monogram + gradient hairline; footer "Powered by Claude"; **never "Claude Code"** in panel UI. RTL via
  CSS `direction` (not `sp-theme dir`), `<bdi dir="ltr">` for commands/timecodes/paths.
- Premiere UXP: manifest v5, `host {app:"premierepro", minVersion:"26.5.0"}`, `requiredPermissions
  {localFileSystem:"fullAccess", network:{domains:["ws://127.0.0.1","http://127.0.0.1"]}}` (fall back to `"all"` only if
  the spike proves the explicit entries fail), icons 23/46 + 24/48 px dark/light, panel preferred ~340×640, min
  280×320. TypeScript + `premierepro-types` + esbuild; every mutation in `project.lockedAccess(() =>
  project.executeTransaction(…))` (undo step "WhyNot Cut build"); components/effects by **match name**.
- Never set PlayerDebugMode (a hook blocks it); Yunus toggles it (H7). Any bridge reinstall needs Premiere/AE
  restarted by Yunus (H7). Never write into a signed extension after install.
- Signing material (self-signed cert) lives outside the repo in `~/.whynot-cut/signing/`; its password in the Windows
  Credential Manager / macOS keychain; never committed or logged.
- Internal renames (D18): `nh_*`→`wnc_*`, `NHPP/NHAE/NHM/NH`→`WNCPP/WNCAE/WNCM/WNC`, env `NH_*`→`WNC_*`/`WHYNOT_*`
  with old names still read for one major version.

### Task 1: T6.1 Command contract v4

JSON Schemas (draft 2020-12) in `whynot-cut/engine/reel/contract/` for every action: `build_project`, `export_frames`,
`close_project_path`, `probe`, `clip_components`, `ae_build_motion`, `ae_readback`, `ae_render`, `ping`, `status`,
`open_project`, `set_player_position`, `render_review` — request `data` and result `readback` shapes derived from the
current `NHPP`/`NHAE` actions and `ppro_build`/`motion_build` read-back code. Golden read-back fixtures in
`whynot-cut/tests/fixtures/contract/` (from recorded real results where they exist in whynot-test outputs, else from
the code's expected shapes; a live re-record happens at T6.9). Contract tests in Python (validate fixtures, validate
every request the engine builds) and in TS (ajv in `adobe/premiere-uxp` test). Protocol 4 constant shared.

### Task 2: T6.2 `reel serve` (engine daemon) (needs T2.17)

Python asyncio + `websockets` (add to the requirements/locks); HTTP endpoints for status + WS for the session;
`reel serve --ensure|--status|--stop` (pidfile + port in `engine.json`); router: connected UXP client → UXP adapter;
CEP adapter (file queue to the CEP daemon); file-queue fallback; progress events; audit log
`~/.whynot-cut/logs/serve-audit.log`. SessionStart hook runs `reel serve --ensure` in the background, idempotently,
≤ 1 s added. Every `reel` host command (`ppro-build`, `ppro-frames`, `ppro-probe`, `motion-build`, `ae-*`) uses the
daemon when up, else the file queue (same results). Panel endpoints `/approve` and `/request` record
`plan-approval.json` `{by:"editor", via:"panel", editor_name, at, fingerprint}` and `panel-requests.json`.
- **Acceptance:** security test suite (wrong token, wrong Host, browser Origin, oversize message, unknown action,
  schema-invalid data → all rejected, audit-logged); reconnect test; IPv6 `::1` not bound; daemon-down → file queue.

### Task 3: T6.3 CEP bridge 3.2.0 hardened and signed

Move CEP sources to `WhyNotCut/adobe/cep-bridge/` (CSXS/manifest.xml, index.html, js/, jsx/wnc_*.jsx, ui/);
`bridge-config.json` → `~/.whynot-cut/bridge/config.json` (nothing written into the extension); JSX libraries ship
inside the bundle with a version handshake (no more `sync_scripts` into the engine home; keep a compat read of the old
location for 3.0); components/effects by match name; frame constant from the sequence fps; only the hidden daemon
extension processes jobs (`who` fixed); heartbeat `{bundle, protocol, host, hostVersion}`; renames per D18 with the
whitelist updated; branded panel UI from `adobe/panel-ui` (CEP build); bump bundle to **3.2.0** everywhere (version
triple test). Signing: `tools/sign_zxp.py` downloads ZXPSignCmd (Adobe-CEP GitHub, pinned sha256) into
`~/.whynot-cut/signing/`, creates the self-signed cert once (`EG Cairo "The Why Not AI" "WhyNot Cut"`, 10 years),
stores the password in the OS credential store, signs with a timestamp (`-tsa`), verifies (`-verify -certinfo`) →
`whynot-cut/adobe/WhyNotCut-Bridge-3.2.0.zxp`. `ppro-install` extracts the signed ZXP into the per-user CEP folder (or
uses UPIA `/install`) and verifies `META-INF/signatures.xml` exists and the files match. Live acceptance at Gate 6
(PlayerDebugMode off by Yunus): loads in Premiere 26.5.2 + AE 26.5; `ppro-build` all checks on 3.2.0; motion build QC;
record whether extract or UPIA works.
