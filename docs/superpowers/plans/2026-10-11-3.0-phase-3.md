## Global Constraints (bind every task)

- Repo root `WhyNotCut/`; plugin `whynot-cut/`; branch `release/3.0`; one commit per task (conventional message ending
  with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`).
- Tests: `bash tools/test.sh` (engine runtime, ≈8 min; `-k` focused). TDD; count never drops; output pristine.
- Skill-description budget (D11, enforced by the Phase 1 test): user-facing ≤ 200 chars, craft ≤ 90, total ≤ 4,000;
  never `disable-model-invocation` on craft skills.
- User-facing vocabulary: three verbs — **drop files · say what you want · approve the plan**. "Gate 0/1/2" and stage
  numbers are internal only; user text says "pick the reels / approve the plan / proof check".
- Product naming "WhyNot Cut"; never "Claude Code" in product UI text meant for editors (docs for developers may).
- Arabic text: Egyptian-friendly; commands always in their own code blocks (RTL safety); write Arabic with Write/Edit.
- Never write into `D:\WhyNot Clients`. Validate with `claude plugin validate --strict` (path from
  `python tools/find_claude.py`) on the marketplace and plugin after each task that touches manifests/skills/agents.
